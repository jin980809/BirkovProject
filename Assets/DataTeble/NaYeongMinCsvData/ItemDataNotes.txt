10.2 무기 4종 등록 (10001~10004)
  기관권총 20발 연사 / 샷건 8발 펠릿6 단발 / 돌격소총 30발 연사 / 스나이퍼 5발 단발
  재장전 2초 전 무기 통일. 탄속은 히트스캔 처리라 projectileSpeed 는 0 으로 둔다.
  내구도·수리비는 5.2 표를 따른다. 파밍 무기는 최대 내구도 상태로 지급한다(획득 담당 처리).

10.1 탄약 4종 등록 (11001~11004)
  1박스 20발. magazineSize 열에 20 을 기록했다.
  무기 행에서 magazineSize 는 탄창 용량, 탄약 행에서는 1박스당 발수를 뜻한다.
  열을 새로 만들지 않으려고 재사용했으니 읽는 쪽에서 itemType 으로 구분할 것.
  중첩 불가(maxStack 1). 기획서 10.1 '무기와 총알, 특수 소모형은 1'.

보호구 6종 등록 (헬멧 13001~13003 / 조끼 12001~12003)
  수리 불가라 repairAmountPerCurrency 는 0 이다. 기획서 6.7 '수리는 못 하게 설정'.
  피격 1회당 내구도 1 차감, 0 이면 영구 파괴.

지푸라기
  가방 25칸을 차지하지 않는 재화로 변경했다. 기획서 10.1 [지푸라기에 대해].
  PlayerInventoryData.currency 에 즉시 합산되며 저장 포맷은 saveVersion 4 다.

확인 필요 (임의로 채우지 않음)
1. 보호구 감쇄 방식이 섞여 있다.
   구형 헬멧 -1, 튼튼 헬멧 -2 는 고정 차감인데
   최고급 헬멧 30%, 구형/튼튼/최고급 조끼 10/20/30% 는 비율이다.
   6.7 과 10.2.1 의 공식은 '적 기본 데미지 - 고정 방어력 총합' 으로 고정 차감뿐이다.
   6.2 는 '둘 다 최고급이면 최대 60% 경감' 이라 비율 합산을 전제한다.
   -> defense 열에는 고정 수치가 명시된 13001(1), 13002(2) 만 채웠고 나머지 4종은 공란이다.
      고정으로 통일할지 비율 열을 새로 둘지 확정 필요.
2. 보호구 최대 내구도 수치가 표에 없다. maxDurability 공란.
3. 10.3 드롭 확률표의 보호구 행이 구형 헬멧 50 / 구형 조끼 50 만 있고
   나머지 4종은 비어 있으며 어느 소스의 확률인지도 불명확하다.
   -> 드롭 테이블에 보호구를 넣지 않았다. 확률표 보완 후 추가한다.
4. 공격속도 단위가 여전히 모호하다. 열 이름은 초/횟수, 해설은 1초당 발사 횟수로 서로 역수다.
   표값(1 / 3 / 2.5 / 0.8)을 fireRate 에 그대로 넣었다. 단위 확정 시 재검토.
5. 6.3 하단의 '아이템 중첩과 관하여' 표에 무기 슬롯 5칸이 남아 있다.
   상단 6.3 표(무기 2 + 장비구 2)가 최신이며 구현은 상단을 따랐다. 구판 잔재로 보인다.
6. 깃털·돌·거울 조각은 10.1 에 드롭 개수가 있으나 10.3 확률표에 여전히 없다.
